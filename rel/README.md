# rel/

Sample images built by `.github/workflows/pages.yml` from `main` and replaced
in place on every build; the commit that put them here names the source
commit. The same files are on the GitHub Pages site under `samples/`.

| File | What it does |
|---|---|
| `sertest-echo-115200.mot` | sends back whatever it receives on SCI1 |
| `sertest-flood-115200.mot` | numbered lines on SCI1 as fast as the line goes |
| `sample1-lcd-115200.mot` | touch-panel UI on the LCD, logging each touch ([smallest-touchpanel-ui](https://github.com/paijp/smallest-touchpanel-ui)) |

All at 115200 bps, for the RX65N Envision Kit. Write them with the web page or
`pi/rxflash.py`.

These images contain startup code generated by Renesas tools, which carries
Renesas Electronics' own notice (for use with Renesas products only); see
[NOTICE](../NOTICE). This is not official Renesas Electronics software and is
